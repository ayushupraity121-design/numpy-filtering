# NumPy Data Filtering

## Description
Use NumPy conditions to identify values that are above, below, or equal to a specified threshold.

## Objective
Practice Boolean indexing and numerical filtering.

## Tools
* Python
* NumPy
* Jupyter Notebook

## Deliverables
* NumPy array containing numerical values
* Filtered results
* Examples using different thresholds

## Hints / Mini Guide
* Use Boolean conditions
* Try conditions such as `data > 50`
* Use Boolean indexing to return matching values

## Suggested Datasets
* Student marks
* Sales values
